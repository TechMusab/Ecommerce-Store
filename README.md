# Multi-Vendor eCommerce Store (MERN Stack)

This project is a full-stack eCommerce platform built with the MERN stack (MongoDB, Express, React, Node.js) that supports multiple vendors. Each vendor can manage their own products, while customers can browse and purchase items from various vendors in one platform.

## Features

- **Multi-Vendor Support**: Vendors can register and manage their own products, view orders, and manage inventory.
- **Product Catalog**: Customers can browse products by categories, sort/filter by price, rating, etc.
- **Shopping Cart**: Customers can add products to the cart, update quantities, and proceed to checkout.
- **Order Management**: Customers can view their order history, and vendors can view and manage incoming orders.
- **Authentication & Authorization**: User authentication via JWT (JSON Web Tokens) for both vendors and customers.
- **Responsive Design**: Optimized for both desktop and mobile views.
- **Payment Integration**: Placeholder for payment gateway integration (e.g., Stripe, PayPal).
- **Admin Panel**: Admin users can manage vendors, view reports, and handle site-wide configurations.

## Technologies Used

- **Frontend**:
  - React.js
  - Redux for state management
  - React Router for navigation
  - Axios for API calls
  - Material-UI for UI components

- **Backend**:
  - Node.js with Express.js
  - MongoDB with Mongoose for database management
  - JWT (JSON Web Tokens) for user authentication
